How it works

01 / LABEL

Public reviews in

Star ratings become a noisy 3-class label: 1–2 negative, 3 neutral, 4–5 positive. No private data.

02 / TRAIN

Small transformer

Frozen DistilBERT embeddings + logistic regression: 0.690 accuracy / 0.689 macro F1 on 2,880 train / 720 eval reviews.

03 / CLUSTER

Themes with quotes

TF-IDF + KMeans on negative reviews, with top terms, nearest-neighbour quotes and a suggested experiment per theme.

What this is not

Not an official company analysis. This is an independent read of public reviews. Not a production classifier. The model is a lightweight, inspectable baseline — treat the scores as directional. Not causal. Themes are hypotheses; validate them with support tickets, product analytics and user research before shipping.
